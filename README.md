# Gnome Center

Overview search on a small window for Gnome 51.

## How to install

```sh
git clone <this repo>
cd gnome-center
./install.sh
```

<kbd>Ctrl</kbd>+<kbd>Super</kbd>+<kbd>Space</kbd> is the default keybind which can be changed from the settings.

## Settings

- Shortcut/keybind
- Height/width
- Window transparency

## Uninstall

```sh
gnome-extensions uninstall gnome-center@sophiescodes.github.io
```
